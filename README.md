# Buku Kas

Project ini dibuat untuk memenuhi tugas **Pengembangan Web (PW)**.

## Identitas

- **Mata Pelajaran:** Pengembangan Web (PW)
- **Tema:** Buku Kas
- **No. Absen:** 35

## Deskripsi

Buku Kas adalah program sederhana berbasis PHP yang digunakan untuk mencatat transaksi kas masuk dan kas keluar serta menghitung saldo secara otomatis.

## Fitur

- Menambahkan data kas masuk
- Menambahkan data kas keluar
- Menampilkan data buku kas
- Mengedit data kas
- Menghapus data kas
- Menghitung total kas masuk
- Menghitung total kas keluar
- Menghitung saldo akhir secara otomatis

## Teknologi

- PHP
- HTML
- CSS
- Session PHP

Pastikan PHP sudah terinstall.
